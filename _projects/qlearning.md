## Project Overview

Capstone project that developed a 1D robot using ultrasonic sensors and Q-learning to guide humans to a target.

## Key Features

- Real-time learning from user input
- Sensor-actuator loop via MATLAB-PIC interface
- Achieved high accuracy with low training episodes

## Technical Implementation

PIC microcontroller collected sensor data, transmitted it to MATLAB. MATLAB controlled learning and decision-making.

## Results

Reached 95% success rate in <50 episodes. Recognized as one of the best technical capstones in the class.
