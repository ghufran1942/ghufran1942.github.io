## Project Overview

Designed and implemented a human-robot collaboration system using aerial (drone) and ground robots for real-time interaction.

## Key Features

- Real-time communication between UAVs and UGVs
- Sensor fusion and visual localization
- PID tuning and motion planning
- Vicon integration for localization accuracy

## Technical Implementation

ROS-based architecture on Jetson and Pixhawk. TCP/IP protocols for robot comms. Used `journalctl`, `netstat`, and `systemctl` for debugging.

## Results

Demonstrated reliable coordination in simulated and real environments. Enabled precision tasks with feedback loops.
